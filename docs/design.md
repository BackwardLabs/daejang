# 대장 웹 디자인 가이드

대장 웹의 공개 랜딩과 실제 제품 화면에 적용하는 디자인 시스템은 저장소 루트의 [DESIGN.md](../DESIGN.md)를 사용합니다.

제품 기준판은 Figma의 [GIWA-70 Frontend Common Template](https://www.figma.com/design/ugpKU5ACV3biVhVQbmz6wr/daejang-web?node-id=1077-2448)이고, 랜딩 기준 화면은 [GIWA Daejang — Mineral Orange CTA / Layout v6](https://www.figma.com/design/ugpKU5ACV3biVhVQbmz6wr/daejang-web?node-id=969-448)입니다. 구현은 루트 `DESIGN.md`의 typography, shell, component, state 계약을 우선합니다.
